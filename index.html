What is Orchestra?

Orchestra is a free macOS desktop app that monitors AI coding agent sessions in real-time. When you run multiple Claude Code sessions in parallel, Orchestra provides a single dashboard to track each session's status, current activity, and progress.

Orchestra integrates with Claude Code through its Hooks feature. As Claude Code works, it sends events (tool use, task completion, permission requests) to Orchestra's local HTTP server. Orchestra aggregates these events and displays them in a real-time dashboard with smart notifications, so you never miss when an agent needs your attention.

Built with Tauri (Rust + React), Orchestra runs as a lightweight native macOS app with minimal resource usage. It supports one-click jumping to any session via tmux integration, letting you switch context instantly without losing your flow.

FAQ

Frequently asked questions about Orchestra.

Is Orchestra free? expand_more

Yes. Orchestra is completely free to download and use. There are no paid plans or subscriptions.

Does Orchestra send my data to external servers? expand_more

No. Orchestra runs entirely on your local machine. The HTTP server only listens on localhost (127.0.0.1) and never sends data externally. Your session data, command history, and working directories stay completely private.

Which AI coding agents does Orchestra support? expand_more

Orchestra currently supports Claude Code through its Hooks integration. It monitors session status, tool usage, and permission requests in real-time.

Does it work on Intel Macs? expand_more

Currently, Orchestra only supports Apple Silicon Macs (M1, M2, M3, M4). Intel Mac support is not available at this time.

How does Orchestra integrate with Claude Code? expand_more

Orchestra uses Claude Code's Hooks feature. When configured, Claude Code sends events (tool use, task completion, permission requests) to Orchestra's local HTTP server on port 3008, which aggregates and displays them in a real-time dashboard with smart notifications.
