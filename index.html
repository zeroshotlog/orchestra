How it works

Hooks in. Cues out. Nothing in between leaves your Mac.

Every agent CLI already has a hook system. Orchestra plugs into it with one setup script, listens on localhost, and turns the stream of events into a dashboard you can actually act on.

01 · Your agents

Hooks fire on every event

13 Claude Code events, 10 for Codex, 12 for Kimi: tool use, permission requests, subagent starts, compaction, session end.

$ ./scripts/setup-claude-hooks.sh
✓ 13 hooks + statusline → ~/.claude/settings.json
02 · Orchestra

A Rust server on localhost:3008

Events land in an in-memory store, become session state, cues and usage. Nothing is written anywhere but your disk.

FAQ

Questions, answered.

Is Orchestra free?
Yes. Orchestra is completely free to download and use. There are no paid plans, subscriptions or accounts.
Does Orchestra send my data to external servers?
No. Orchestra runs entirely on your Mac. Its HTTP server only listens on 127.0.0.1:3008, it never sends data externally, and there is no telemetry. Session data, prompts and working directories stay on your disk.
Which AI coding agents does Orchestra support?
Claude Code, Codex CLI and Kimi Code CLI, each through its own hook system and with its own badge. A hooks template for Gemini CLI is included. If Ollama is running, its models can be used as workers in Orchestration and are billed at $0.
Does it work on Intel Macs?
Currently, Orchestra only supports Apple Silicon Macs (M1, M2, M3, M4). Intel Mac support is not available at this time.
How does Orchestra integrate with Claude Code?
Through Claude Code's Hooks feature. A setup script registers 13 hook events plus a statusline command in ~/.claude/settings.json. As Claude Code works, it posts events (tool use, completion, permission requests, subagent activity) to Orchestra's local server, which turns them into the dashboard, cues and notifications. The statusline adds per-session effort, context usage and rate limits.
What do I need for Orchestration?
Node.js. The engine is bundled with the app and installed to ~/.orchestra/engine on first use (dependencies install once, a few tens of seconds). Workers are the CLIs you already have: Claude Code, Codex, Kimi Code CLI, or local models via Ollama.
Why does macOS say the app can't be opened?
The app is not signed with an Apple Developer certificate yet. Open System Settings → Privacy & Security and click Open Anyway, or run xattr -cr /Applications/Orchestra.app once. Homebrew installs skip this step.
