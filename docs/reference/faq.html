FAQ ​

Is Orchestra free? ​

Yes, Orchestra is completely free to use.

Does it send my data anywhere? ​

No. All data stays on your local machine. The hook server runs on localhost:3008 and only accepts connections from your local Claude Code sessions. No data is sent to any external server.

Which AI coding agents are supported? ​

Currently, Orchestra supports Claude Code via its Hooks system. Support for additional agents may be added in the future.

What are the system requirements? ​

  • macOS 11.0+ (Big Sur or later)
  • Apple Silicon (M1/M2/M3/M4)
  • tmux (for session jumping)
  • Claude Code installed

How do I install Orchestra? ​

The recommended way is via Homebrew:

bash
brew install --cask zeroshotlog/tap/orchestra

Alternatively, download the DMG from the Releases page.

How do I uninstall Orchestra? ​

  1. Quit Orchestra if it's running
  2. Delete Orchestra.app from /Applications
  3. Remove the hook configuration from ~/.claude/settings.json

Can I use Orchestra without tmux? ​

Orchestra will still monitor your sessions without tmux, but the "Jump to session" feature requires tmux to work. Sessions running outside tmux will appear in the dashboard but won't have a Jump button.

Does Orchestra work with Claude Code Agent Teams? ​

Yes. When you use Claude Code's Agent Teams feature, Orchestra automatically detects team members running in the same tmux window. Team sessions are displayed with rainbow-colored borders, with the Lead and Member roles clearly labeled. Make sure the TeammateIdle and TaskCompleted hooks are configured for team detection to work.

How many hook events do I need to configure? ​

For full functionality, configure all 13 hook events: PreToolUse, PostToolUse, Stop, Notification, SubagentStart, SubagentStop, SessionStart, SessionEnd, UserPromptSubmit, PermissionRequest, PreCompact, TeammateIdle, and TaskCompleted. See the Getting Started guide for the complete configuration.

Does Orchestra track subagents? ​

Yes. When Claude Code spawns subagents (via the Task tool), Orchestra tracks the number of active subagents per session. The session card shows the current subagent count and displays a "Delegating" activity status.

Can I switch between grid and list views? ​

Yes. Use ⌘1 for grid view or ⌘2 for list view, or select from the View menu. Grid view shows detailed session cards, while list view provides a compact row-based layout.

What is the Pomodoro Timer? ​

Orchestra includes a built-in Pomodoro timer to help you manage focused work sessions. You can customize work/break durations, cycle counts, and timer size from the Orchestra menu → Pomodoro Timer. The timer supports drag-and-drop repositioning and automatic work/break cycling.

What are Agent Badges? ​

Agent badges show which AI coding agent is running each session (e.g., Claude, Codex, Gemini). They are automatically detected from hook events. You can toggle badge visibility from Orchestra menu → Show Agent Badges.

Can I search and filter sessions? ​

Yes. Press ⌘F to focus the search bar and filter sessions by title. When multiple tmux sessions are detected, tabs appear at the top for quick filtering by tmux session.
