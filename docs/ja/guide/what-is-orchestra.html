Orchestraとは ​

OrchestraはAIコーディングエージェント（Claude Code等）のセッション状態をリアルタイムで監視するmacOSデスクトップアプリです。Hooksを通じて全てのアクティブなセッションを統合ダッシュボードで管理できます。

課題 ​

複数のClaude Codeセッションを異なるプロジェクトで同時に実行していると、以下のことが把握しにくくなります:

  • どのセッションが入力待ちか
  • どのセッションが権限承認を必要としているか
  • どのセッションがタスクを完了したか
  • どのセッションがサブエージェントやチーム操作を実行中か

ステータスを確認するために、常にターミナルウィンドウを切り替える必要があります。

解決策 ​

Orchestraはバックグラウンドで動作し、全てのClaude Codeセッションを単一のダッシュボードで監視します。セッションがあなたの注意を必要とした時、通知とワンクリックジャンプ機能で素早く対応できます。

主要機能 ​

  • リアルタイム監視 — ライブステータス更新で全セッションを一目で確認
  • スマートキューシステム — 入力待ち・権限要求・エラー時に自動アラート
  • ワンクリックジャンプ — tmux + iTerm2連携でセッション間を瞬時に移動
  • Grid & List表示 — グリッドとリストのレイアウト切り替え、検索、tmuxセッションタブ
  • エージェントバッジ — 各セッションで動作中のAIエージェント（Claude, Codex, Gemini等）を識別
  • チームモード — Claude Code Agent Teamsを自動検出し、虹色枠で視覚化
  • サブエージェント追跡 — セッションごとのアクティブサブエージェント数を追跡
  • ポモドーロタイマー — カスタマイズ可能なWork/Break時間とサイクル管理付きの集中タイマー
  • ネイティブmacOS — システム通知とサウンド対応の軽量Tauriアプリ

仕組み ​

Claude Code Hook → HTTP POST → Orchestra (port 3008) → デスクトップUI
                                                      → システム通知
                                                      → サウンドアラート
  1. Claude Codeがhookイベント（PreToolUse, PostToolUse, Stop, SubagentStart, TeammateIdle等）を発火
  2. 各イベントがcurlでOrchestraのローカルHTTPサーバー（port 3008）に送信
  3. Orchestraがセッション状態を更新しデスクトップUIに表示
  4. セッションが注意を必要とした時、キュー通知がJumpボタン付きで表示
