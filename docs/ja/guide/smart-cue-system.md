# スマートキューシステム

キューシステムはOrchestraの通知メカニズムです。セッションがあなたの注意を必要とした時、ダッシュボード上部にキューが表示されます。

## キューのトリガー

| トリガー | キュータイプ | 説明 |
|---------|------------|------|
| Claudeが応答停止 | WAITING_INPUT | 続行するにはユーザーの入力が必要 |
| 権限要求 | WAITING_PERMISSION | ツール使用の承認が必要 |
| セッションエラー | ERROR | エラーが発生 |
| ステイルセッション | WAITING_INPUT | 設定されたタイムアウト期間中にアクティビティなし |

## キューレーン

キューはダッシュボード上部の専用レーンに表示されます。各キューには以下が表示されます:

- **セッション名** — どのセッションが注意を必要としているか
- **理由** — キューが作成された理由
- **説明** — コンテキストのための最終ログメッセージ
- **Jumpボタン** — セッションに直接移動
- **Dismissボタン** — ジャンプせずにキューを削除

## 自動解決

以下の場合、キューは自動的に解決されます:

- セッションが再び実行を開始した時（新しいツール使用を検出）
- セッションが終了した時
- 手動でキューをDismissした時

## サウンド通知

新しいキューが表示された時、Orchestraはシステムサウンド（Glass）を再生してアラートします。アプリがバックグラウンドにある時も動作します。

## ステイルセッション検出

実行中のセッションが設定可能なタイムアウト期間中にhookイベントを受信しなかった場合、Orchestraは自動的にWAITING_INPUTキューを作成します。これはClaude Codeが停止したがStopフックが発火しなかったケースをカバーします。
