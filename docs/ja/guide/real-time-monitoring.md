# リアルタイム監視

Orchestraは全てのClaude Codeセッションをライブステータス更新で単一のダッシュボードから監視します。

## 仕組み

Claude Code実行時、重要なタイミングでhookイベントが発火されます。OrchestraはこれらのイベントをHTTPで受信し、ダッシュボードをリアルタイムで更新します。

## セッションの状態

各セッションカードは現在の状態を表示します:

| ステータス | 意味 |
|-----------|------|
| **Running** | Claudeがアクティブに作業中（読み取り、書き込み、実行） |
| **Thinking** | ツール呼び出しの間にClaudeが処理中 |
| **Waiting Input** | Claudeが停止しユーザーの入力を待機中 |
| **Waiting Permission** | 続行するために権限が必要 |
| **Done** | セッションが終了 |

## アクティビティタイプ

Claudeが現在何をしているかも表示されます:

- **Reading** — ファイル読み取り（Read, Glob, Grepツール）
- **Writing** — ファイルの編集・作成（Edit, Writeツール）
- **Running** — コマンド実行（Bashツール）
- **Coding** — その他の開発ツール使用中
- **Idle** — アクティブなツール使用なし

## セッションカード

各セッションカードには以下が表示されます:

- **タイトル** — 作業ディレクトリ名から自動取得
- **ステータスバッジ** — カラーコード付きの現在のセッション状態
- **最終アクティビティ** — 最新のツールやコマンド出力
- **Jumpボタン** — ターミナルセッションへのワンクリックナビゲーション
