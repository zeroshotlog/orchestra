よくある質問 ​

Orchestraは無料ですか？ ​

はい。Orchestraは完全に無料で使用できます。

データはどこかに送信されますか？ ​

いいえ。全てのデータはローカルマシンに保存されます。hookサーバーはlocalhost:3008で動作し、ローカルのClaude Codeセッションからの接続のみ受け付けます。外部サーバーへのデータ送信は一切ありません。

どのAIコーディングエージェントに対応していますか？ ​

現在、Hooks機能を通じてClaude Codeをサポートしています。将来的に他のエージェントへの対応も検討しています。

システム要件は？ ​

  • macOS 11.0+（Big Sur以降）
  • Apple Silicon（M1/M2/M3/M4）
  • tmux（セッションジャンプ用）
  • Claude Code（インストール済み）

インストール方法は？ ​

Homebrewでのインストールを推奨しています:

bash
brew install --cask zeroshotlog/tap/orchestra

またはReleasesページからDMGをダウンロードしてください。

アンインストール方法は？ ​

  1. Orchestraが実行中の場合は終了
  2. /ApplicationsからOrchestra.appを削除
  3. ~/.claude/settings.jsonからhook設定を削除

tmuxなしでも使えますか？ ​

tmuxなしでもセッションの監視は可能ですが、「セッションにジャンプ」機能はtmuxが必要です。tmux外で実行されているセッションはダッシュボードに表示されますが、Jumpボタンは使用できません。

Claude CodeのAgent Teams機能に対応していますか？ ​

はい。Claude CodeのAgent Teams機能を使用すると、Orchestraは同じtmuxウィンドウ内で実行されているチームメンバーを自動検出します。チームセッションは虹色のボーダーで表示され、LeadとMemberのロールが明確にラベル付けされます。チーム検出が動作するには、TeammateIdleとTaskCompletedのhookが設定されている必要があります。

hookイベントはいくつ設定する必要がありますか？ ​

全機能を利用するには、13個のhookイベントを設定してください: PreToolUse, PostToolUse, Stop, Notification, SubagentStart, SubagentStop, SessionStart, SessionEnd, UserPromptSubmit, PermissionRequest, PreCompact, TeammateIdle, TaskCompleted。詳細な設定ははじめにガイドを参照してください。

サブエージェントの追跡はできますか？ ​

はい。Claude CodeがTaskツールでサブエージェントを起動すると、Orchestraはセッションごとのアクティブサブエージェント数を追跡します。セッションカードには現在のサブエージェント数が表示され、「Delegating」アクティビティステータスになります。

グリッド表示とリスト表示を切り替えられますか？ ​

はい。⌘1でグリッド表示、⌘2でリスト表示に切り替えるか、Viewメニューから選択できます。グリッド表示は詳細なセッションカード、リスト表示はコンパクトな行ベースのレイアウトです。

ポモドーロタイマーとは？ ​

集中作業セッションの管理をサポートするポモドーロタイマーを内蔵しています。Work/Breakの時間、サイクル数、タイマーサイズをOrchestraメニュー → Pomodoro Timerからカスタマイズ可能です。ドラッグ&ドロップでの位置変更やWork/Breakの自動サイクルに対応しています。

エージェントバッジとは？ ​

各セッションで動作中のAIコーディングエージェント（Claude, Codex, Gemini等）を表示するバッジです。hookイベントから自動的に検出されます。バッジの表示/非表示はOrchestraメニュー → Show Agent Badgesから切り替えられます。

セッションの検索やフィルターはできますか？ ​

はい。⌘Fで検索バーにフォーカスし、タイトルでセッションをフィルターできます。複数のtmuxセッションが検出されると、上部にタブが表示され、tmuxセッション単位でのフィルターが可能です。
